## Pasos

1. Construye las regiones que el handoff lista. No añadas una navegación, un pie o un widget para que se vea terminada.
2. Usa la biblioteca de componentes del proyecto cuando la tiene. Un componente nuevo necesita una razón que la biblioteca no cubre.
3. Usa el elemento nativo que ya tiene el rol. Añade ARIA solo donde el requisito de accesibilidad dice que el elemento nativo no alcanza.
4. Cada cadena que la persona ve sale del archivo de textos, incluido el nombre accesible.
