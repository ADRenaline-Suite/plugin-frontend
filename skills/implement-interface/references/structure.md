The screen grows a region the handoff does not have.

## Steps

1. Build the regions the handoff lists. Do not add a nav, a footer, or a widget to make it look finished.
2. Use the project's component library when it has one. A new component needs a reason the library cannot cover.
3. Use the native element that already has the role. Add ARIA only where the accessibility requirement says the native element is not enough.
4. Every string the user sees comes from the copy file, including the accessible name.
